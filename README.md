# Aplicacion-CRUD-en-C-
# Sistema Universidad

Este proyecto es una aplicación desarrollada en C++ que se conecta a una base de datos MySQL utilizando ODBC.
El sistema permite gestionar información académica mediante un menú interactivo en consola.

* Listar alumnos registrados
* Insertar nuevos alumnos
* Eliminar alumnos existentes
* Listar cursos disponibles
* Registrar nuevos cursos
* Listar secciones
* Registrar nuevas seccioneS
* Asignar cursos a alumnos
* Asignar sección a alumnos
* Visualizar alumnos con sus cursos y sección (uso de JOIN)

 Base de Datos

Nombre: `universidad`
Tablas utilizadas:
* alumnos
* cursos
* secciones
* alumnos_cursos
* alumnos_seccion

Requisitos

* MySQL
* MySQL ODBC Driver
* Compilador C++ (Dev C++)
